# Mehran Estates — Pakistani WordPress-Style Business Website

An 8-page, responsive real-estate business website concept for a Pakistani property consultancy.

## Pages
1. Home
2. About
3. Services
4. Properties
5. Projects
6. Blog / Insights
7. FAQ
8. Contact

## Brand
**Mehran Estates** — a professional, premium Pakistani real-estate brand.

## Tech
HTML5, CSS3, vanilla JavaScript. The site is static and can be opened directly in VS Code with Live Server or hosted on GitHub Pages.

## GitHub
Upload all files and folders while preserving the structure:
- `index.html`
- `about.html`
- `services.html`
- `properties.html`
- `projects.html`
- `blog.html`
- `faq.html`
