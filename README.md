# Mehran Estates  Real Estate Website

Mehran Estates is a modern and responsive real estate website designed for a property-focused business.

The project provides a professional digital presence for a real estate brand, with a clean layout focused on presenting properties, services, and essential information to potential buyers and clients.

## Features

* Professional real estate design
* Property-focused presentation
* Responsive layout
* Clear and simple navigation
* Real estate services presentation
* Contact and inquiry sections
* Call-to-action sections
* Mobile-friendly interface
* Clean and modern visual design
